Llavero de emoji

Elige un emoji y descarga un SVG listo para el láser: el emoji se graba en negro y alrededor lleva un borde de corte en rojo, con una anilla opcional para colgarlo como llavero. Todo ocurre en tu navegador: no se sube nada a ningún servidor.
